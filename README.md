# Qubators Tracker

Simple order and customer tracker for businesses that sell through WhatsApp and Instagram.

**Promise:** Never lose an order again.

**Flow:** Record → Track → Get Paid → Deliver → Follow Up

- `Docs/Qubators Order and Customer Tracker.md` — PRD (vision + requirements)
